# TacoLinux Documentaition
this folder is dedicated to Documentaition of tacolinux how to use it and how it works.

if you cant understand something there will probably be a help here or you can check out  

- arch wiki
- gentoo handbook

both of these are great sources of Documentaition for linux. this folder is only about tacolinux and will only help you with tacolinux.  

to get started with the distrobution read [install.md]
to manage the system read [management.md]
to update. well... you cant.  

an update means having to reset the entire system. for updates we recommend just updating the initramfs and kernel.  
a guide on that can be found on [updating.md]
